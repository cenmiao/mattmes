# 0011-前端设计规范

## 状态

已接受

## 背景

前端采用"工业精密"深色风格。配色、字体、间距等 token 如果散落在组件里，页面之间会漂移。此 ADR 记录设计系统约定，实际 token 定义在 `mattmes-ui/src/styles/theme.css`。

> 变量名一律以 `theme.css` 中的实现为准。本 ADR 与早期文档中的 `--color-primary` 式命名不同，实现用的是 `--primary-color`。

## 决策

### 1. 配色

| 用途 | 变量 | 色值 |
|------|------|------|
| 主色 | `--primary-color` | `#0EA5E9` |
| 主色浅 | `--primary-light` | `#38BDF8` |
| 主色深 | `--primary-dark` | `#0284C7` |
| 成功 | `--success-color` | `#10B981` |
| 警告 | `--warning-color` | `#F59E0B` |
| 错误 | `--error-color` | `#F43F5E` |
| 数据高亮 | `--data-highlight` | `#22D3EE` |

### 2. 层级

背景自深到浅：

| 层级 | 变量 | 色值 | 用途 |
|------|------|------|------|
| L0 | `--surface-l0` | `#0F172A` | 最深背景 |
| L1 | `--surface-l1` | `#1E293B` | 主背景、侧边栏、卡片 |
| L2 | `--surface-l2` | `#334155` | 表格、输入框 |
| L3 | `--surface-l3` | `#475569` | 边框、分隔线 |

内容自亮到暗：

| 层级 | 变量 | 色值 | 用途 |
|------|------|------|------|
| C1 | `--content-c1` | `#F8FAFC` | 主文字 |
| C2 | `--content-c2` | `#CBD5E1` | 次要文字 |
| C3 | `--content-c3` | `#94A3B8` | 辅助文字 |
| C4 | `--content-c4` | `#64748B` | 禁用文字 |

### 3. 字体

| 用途 | 变量 | 字体 |
|------|------|------|
| 标题 / 品牌 | `--font-brand` | JetBrains Mono, SF Mono |
| 正文 | `--font-body` | Inter, 系统字体 |
| 数据展示 | `--font-data` | IBM Plex Mono |

工号、IP、时间等数据使用 `--font-data` 等宽字体。

### 4. 间距与圆角

间距：`--spacing-xs` 4px、`--spacing-sm` 8px、`--spacing-md` 16px、`--spacing-lg` 24px、`--spacing-xl` 32px、`--spacing-2xl` 48px。

圆角：`--radius-sm` 4px（标签、徽章）、`--radius-md` 8px（输入框、按钮）、`--radius-lg` 12px（卡片）、`--radius-xl` 16px（弹窗）。

### 5. 布局

```
Dashboard（主布局）
├── Sidebar（侧边栏，展开 240px / 收起 72px）
│   ├── Logo
│   ├── Menu（动态路由）
│   └── Version
├── Header（顶部导航，64px）
│   ├── CollapseBtn
│   ├── Breadcrumb
│   └── UserDropdown
└── Content
    └── <router-view />
```

### 6. 表格与交互

- 状态用 Switch 开关或徽章
- 角色用标签组
- 操作用图标按钮组，悬停变色
- 表格行悬停使用主色半透明背景

### 7. 关键页面要点

**登录页**：居中卡片布局，背景网格图案 + 辉光球特效；账号冲突弹窗需展示上次登录时间与 IP；错误提示需显示原因及剩余锁定时间。

**修改密码页**：密码强度指示器（进度条 + 文字），要求检查列表（8 位、字母、数字），三档强度——弱（红）、中等（橙）、强（绿）。

## 理由

深色基调 + 等宽数据字体是为了让产线看板在强光环境下仍可读，并让 SN、工号这类标识在密集表格里对齐可扫。集中定义 token 后，新页面只需引用变量，不必重新调色。

## 影响

- 新页面必须引用 `theme.css` 变量，不得硬编码色值。
- Element Plus 组件通过覆盖 `--el-*` 变量接入该色板，见 `theme.css`。
