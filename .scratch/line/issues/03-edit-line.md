# 03: 编辑线体

**What to build:** 管理员能修改已有线体的名称、描述与状态。编码在编辑弹窗中以只读形式展示且不随请求提交——编码是业务唯一标识，改动会让引用方对不上，因此后端也不接受该字段。针对不存在的 ID 编辑需返回 400 而非抛出系统异常。

**Blocked by:** 02 (新增线体)

**Status:** ready-for-agent

- [ ] 编辑接口接受 ID、名称、描述、状态，返回被编辑的 ID
- [ ] 编辑时名称必填校验与新增一致，为空或纯空白返回 400
- [ ] 编辑时名称长度超过 100 返回 400
- [ ] 编辑不存在的 ID 返回 400 与明确提示，不抛系统异常
- [ ] 编辑请求体中不包含编码字段，即使传入也不会被持久化
- [ ] 编辑成功后列表刷新可见更新后的名称、描述与状态
- [ ] 编辑弹窗中编码输入框为只读禁用态
- [ ] 打开编辑弹窗时表单预填当前行的名称、描述与状态
- [ ] 编辑按钮仅在拥有 `line:edit` 时渲染
- [ ] 后端集成测试覆盖编码不可修改与不存在 ID 两个分支
