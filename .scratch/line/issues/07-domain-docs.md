# 07: 领域文档更新

**What to build:** 把"线体"确立为项目的正式领域术语，并记录它与既有主数据的关系边界。当前领域层级是项目 → 料号 → 路由 → 工序，线体不在其中；若不写进文档，后来者很可能造出"产线""生产线""车间"等同义词，或误以为线体应该挂在工序之下。此票不新开 ADR——该决策不难逆转、不反直觉、没有真实取舍，不满足开 ADR 的三条判据。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 领域词条表新增"线体"词条，定义为承载生产作业的物理产线单元
- [ ] 词条明确线体本期不与工序、路由、工单绑定
- [ ] 词条明确线体编码全局唯一且创建后不可修改
- [ ] 词条的 Avoid 项列出产线、生产线、车间
- [ ] 领域业务规则文档的主数据约束表补入线体一行，说明其为独立主数据
- [ ] 不新增 ADR 文件
- [ ] 词条正文不含实现细节，仅描述概念
