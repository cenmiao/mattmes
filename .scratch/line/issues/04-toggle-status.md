# 04: 启用与禁用切换

**What to build:** 管理员在列表里直接拨动开关即可切换线体的启停状态，无需打开编辑弹窗。这是列表内的即时操作，成功后有明确反馈；失败时开关必须回弹到原值，否则界面会显示与服务端不符的状态，用户会误以为已生效。

**Blocked by:** 02 (新增线体)

**Status:** ready-for-agent

- [ ] 状态接口接受 ID 与目标状态，返回该 ID
- [ ] 目标状态为 1 时置为启用，为 0 时置为禁用
- [ ] 目标状态为 0 与 1 之外的值返回 400
- [ ] 对不存在的 ID 切换状态返回 400
- [ ] 列表中开关的启用值映射为 1、禁用值映射为 0
- [ ] 切换成功后列表按当前筛选条件重新查询
- [ ] 切换失败时开关回弹到切换前的值
- [ ] 切换失败时显示服务端返回的错误信息
- [ ] 状态开关仅在拥有 `line:edit` 时渲染
- [ ] 后端集成测试覆盖状态切换成功与非法状态值两个分支
