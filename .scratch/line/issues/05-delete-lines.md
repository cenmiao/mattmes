# 05: 单条与批量删除

**What to build:** 管理员能删除单条线体，也能勾选多条后批量删除。两者都是逻辑删除，删除后列表不再显示该记录，但数据仍在库中可追溯。因为本期线体与任何实体都无关联，删除不做关联校验——这是有意为之，与本 spec 的 Out of Scope 一致。关键边界是编码唯一性：删除后该编码仍占用唯一索引，由 02 的查重逻辑负责给出可读提示。

**Blocked by:** 02 (新增线体)

**Status:** ready-for-agent

- [ ] 单条删除接口接受 ID，执行逻辑删除，返回该 ID
- [ ] 删除不存在的 ID 返回 400
- [ ] 删除后列表查询不再返回该记录
- [ ] 删除操作不因任何关联关系被阻止
- [ ] 批量删除接口接受 ID 数组，逐条校验存在性后统一逻辑删除
- [ ] 批量删除传入空数组返回 400
- [ ] 批量删除中存在不存在 ID 时返回 400 且不产生部分删除
- [ ] 批量删除后列表与总数同步刷新
- [ ] 单条删除前弹确认框并显示该线体的名称
- [ ] 批量删除前弹确认框并显示将要删除的条数
- [ ] 未勾选任何行时批量删除按钮为禁用态
- [ ] 删除与批量删除按钮仅在拥有 `line:delete` 时渲染
- [ ] 后端集成测试覆盖逻辑删除后查不到、批量删除、空数组与不存在 ID 四个分支
