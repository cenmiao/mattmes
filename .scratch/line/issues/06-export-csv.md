# 06: 导出 CSV

**What to build:** 管理员按当前查询条件导出线体数据为 CSV 文件，可离线分析或转交他人。与工序导出相比有一处刻意的行为差异：本模块必须在响应体开头写入 UTF-8 BOM，否则 Excel 打开后中文乱码。工序的 CSV 缺 BOM 是既有缺陷，另行立项修复，不在本票范围内。另一处易错点是描述字段可能包含逗号、双引号或换行，必须按 CSV 规则用引号包裹并转义内部引号，否则导出文件会错列。

**Blocked by:** 02 (新增线体)

**Status:** ready-for-agent

- [ ] 导出接口接受与列表查询相同的筛选条件，一次性导出全部匹配记录而非当前页
- [ ] 响应内容类型为 CSV 且字符集为 UTF-8
- [ ] 响应体以 UTF-8 BOM 开头
- [ ] 响应头包含 attachment 形式的文件名，文件名带时间戳
- [ ] CSV 表头为 7 列：ID、线体编码、线体名称、描述、启用状态、创建人、创建时间
- [ ] 状态列导出原始值 1 或 0，不转换为中文
- [ ] 描述含逗号、双引号或换行时被正确包裹与转义，解析后列数一致
- [ ] 导出遵循当前筛选条件，与列表所见数据一致
- [ ] 前端导出后触发文件下载，文件名与响应头一致
- [ ] 导出按钮仅在拥有 `line:export` 时渲染
- [ ] 后端集成测试断言响应体以 BOM 开头、表头为 7 列、含特殊字符的描述转义正确
